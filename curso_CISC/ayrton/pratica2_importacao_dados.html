7  Parte 1 — Importação com microdatasus (R)

Nesta prática, trabalharemos com dois sistemas principais do DATASUS:

Sistema O que contém Sigla do arquivo
SIM Declarações de Óbito DO
SIH Internações Hospitalares RD

Código do município IBGE: cada município brasileiro tem um código de 7 dígitos definido pelo IBGE. Exemplo: Rio de Janeiro = 3304557. Este código é a chave que usaremos para filtrar os dados para o seu município de interesse. Consulte o código em: https://www.ibge.gov.br/explica/codigos-dos-municipios.php

Caso já tenha seu dado em mãos, pule para a última seção desta prática!

O microdatasus é um pacote R que automatiza o download e a leitura dos microdados do DATASUS, poupando a necessidade de acessar o FTP manualmente.

7.1 1.1 Instalação

# Instalar o microdatasus (via remotes, pois não está no CRAN)
install.packages("remotes")
remotes::install_github("rfsaldanha/microdatasus")

# Pacotes auxiliares
install.packages(c("tidyverse", "lubridate"))

o microdatasus depende do pacote read.dbc, que requer o Rtools (Windows) ou ferramentas de compilação (Linux/macOS). Certifique-se de que estão instalados (ver Prática 1).

7.1.1 1.2 Baixando dados do SIM (óbitos)

library(microdatasus)
library(tidyverse)

# Definir o município de interesse (código IBGE de 6 dígitos)
# Exemplo: Rio de Janeiro = 330455
cod_municipio <- "330455"

# Baixar dados do SIM para o estado do Rio de Janeiro, anos 2020-2022
dados_sim <- fetch_datasus(
  year_start  = 2020,
  year_end    = 2022,
  uf          = "RJ",          # sigla do estado
  information_system = "SIM-DO" # Sistema de Informação sobre Mortalidade
)

# Processar as variáveis (decodifica categorias, converte datas, etc.)
dados_sim <- process_sim(dados_sim)

glimpse(dados_sim)

process_sim() é uma função do próprio microdatasus que transforma o arquivo bruto do SIM em um data frame mais legível e pronto para análise. Entre as principais operações:

  • Converte datas — campos como DTOBITO, DTNASC e DTATESTADO, que chegam como texto no formato DDMMAAAA, são convertidos para o tipo Date do R

  • Decodifica categorias — variáveis codificadas numericamente (como SEXO, RACACOR, CAUSABAS) recebem rótulos descritivos (ex.: 1 → "Masculino")

  • Padroniza o código do município — CODMUNRES e CODMUNOCOR são ajustados para 6 ou 7 dígitos, conforme necessário para cruzamento com tabelas do IBGE

  • Calcula a idade — quando possível, deriva a variável de idade em anos a partir de DTNASC e DTOBITO

O argumento uf define o estado de onde os dados serão baixados. Sempre baixe pelo estado e depois filtre pelo município — o DATASUS organiza os arquivos por UF.

7.1.2 1.3 Filtrando pelo município

# Filtrar pelo código do município (coluna CODMUNRES = município de residência)
dados_sim_municipio <- dados_sim |>
  filter(CODMUNRES == cod_municipio)

# Verificar
nrow(dados_sim_municipio)
head(dados_sim_municipio)

Variáveis de município no SIM:

  • CODMUNRES — município de residência do falecido
  • CODMUNOCOR — município de ocorrência do óbito

Para análises de saúde local, utilize CODMUNRES.

7.1.3 1.4 Baixando dados do SIH (internações)

# Baixar dados do SIH (Autorização de Internação Hospitalar)
dados_sih <- fetch_datasus(
  year_start  = 2020,
  month_start = 1,
  month_end = 3,
  year_end    = 2022,
  uf          = "RJ",
  information_system = "SIH-RD" # Registro de AIH aprovadas
)

dados_sih <- process_sih(dados_sih)

# Filtrar pelo município de residência do paciente
dados_sih_municipio <- dados_sih |>
  filter(MUNIC_RES == cod_municipio)

nrow(dados_sih_municipio)

De maneira análoga à process_sim(), a função process_sih() aplica transformações equivalentes aos dados brutos do SIH. As principais:

  • Converte datas — campos como DT_INTER (data de internação) e DT_SAIDA (data de saída) são convertidos para o tipo Date

  • Calcula o tempo de internação — deriva automaticamente a variável DIAS_PERM como diferença entre entrada e saída, quando ausente ou inconsistente

  • Decodifica categorias — variáveis como COBRANCA, COMPLEX e INSTRU recebem rótulos legíveis

  • Padroniza municípios — MUNIC_RES e MUNIC_MOV são padronizados para cruzamento com o IBGE

7.1.4 1.5 Salvando os dados preparados

# Salvar em formato .rds (compacto, nativo do R)
saveRDS(dados_sim_municipio,    "dados/sim_municipio.rds")
saveRDS(dados_sinasc_municipio, "dados/sinasc_municipio.rds")
saveRDS(dados_sih_municipio,    "dados/sih_municipio.rds")

# Ou em .csv para compartilhamento
write_csv(dados_sim_municipio, "dados/sim_municipio.csv")

7.2 Parte 2 — Acesso direto via FTP (R)

O DATASUS disponibiliza os arquivos .dbc diretamente em seu servidor FTP. Este método é útil quando você já tem um domínio maior sobre os arquivos ou quando o microdatasus não cobre o período desejado.

7.3 2.1 Estrutura do FTP do DATASUS

O endereço base é: ftp://ftp.datasus.gov.br/dissemin/publicos/

A estrutura dos diretórios segue o padrão:

ftp://ftp.datasus.gov.br/dissemin/publicos/
  ├── SIM/
  │   └── CID10/DORES/        # Óbitos CID-10
  │       └── DORJ2022.dbc    # DO + UF + ano
  └── SIHSUS/
      └── ST/RD/              # AIH aprovadas
          └── RDRJ2201.dbc    # RD + UF + ano + mês

Nota sobre o FTP: o servidor FTP do DATASUS pode apresentar instabilidade. Se o download falhar, aguarde alguns minutos e tente novamente. Para downloads grandes, prefira horários fora do horário comercial.

7.4 2.2 Download via R

library(tidyverse)

# Instalar read.dbc para ler arquivos .dbc
install.packages("read.dbc")
library(read.dbc)

# Função auxiliar para baixar e ler um arquivo .dbc do FTP
baixar_dbc <- function(url_ftp, destino) {
  download.file(url_ftp, destfile = destino, mode = "wb", method = "auto")
  read.dbc(destino)
}

# Exemplo: SIM do Rio de Janeiro, ano 2022
url_sim_rj_2022 <- "ftp://ftp.datasus.gov.br/dissemin/publicos/SIM/CID10/DORES/DORJ2022.dbc"

dados_sim_ftp <- baixar_dbc(
  url_sim_rj_2022,
  destino = "dados/DORJ2022.dbc"
)

glimpse(dados_sim_ftp)

7.5 2.3 Download de múltiplos anos

# Definir anos de interesse
anos <- 2019:2022
uf   <- "RJ"

# Construir URLs e baixar todos os arquivos
dados_sim_lista <- map(anos, function(ano) {
  url <- paste0(
    "ftp://ftp.datasus.gov.br/dissemin/publicos/SIM/CID10/DORES/DO",
    uf, ano, ".dbc"
  )
  arquivo <- paste0("dados/DO", uf, ano, ".dbc")

  message("Baixando: ", url)
  download.file(url, destfile = arquivo, mode = "wb", quiet = TRUE)
  read.dbc(arquivo)
})

# Combinar todos os anos
dados_sim_ftp_todos <- bind_rows(dados_sim_lista)

# Filtrar pelo município
cod_municipio <- "3304557"
dados_sim_ftp_municipio <- dados_sim_ftp_todos |>
  filter(CODMUNRES == cod_municipio)

7.6 2.4 Download via SIH (por mês)

O SIH tem arquivos mensais. O padrão de nome é RD + UF + ano (2 dígitos) + mês (2 dígitos):

Veja que a função url_sih é necessária para construir o url correto visto que a partir de 2007 houve uma modificação na base.

url_sih <- function(uf, ano2, mes) {
  ano4 <- as.integer(paste0("20", ano2))  # "22" -> 2022L (inteiro)
  
  base <- ifelse(
    ano4 >= 2008,
    "ftp://ftp.datasus.gov.br/dissemin/publicos/SIHSUS/200801_/Dados/",
    "ftp://ftp.datasus.gov.br/dissemin/publicos/SIHSUS/199201_200712/Dados/"
  )
  
  paste0(base, "RD", toupper(uf), ano2, mes, ".dbc")
}


# Exemplo: SIH RJ, janeiro a dezembro de 2022
meses <- sprintf("%02d", 1:12)
ano2  <- "22"
uf    <- "RJ"

dados_sih_lista <- map(meses, function(mes) {
  url     <- url_sih(uf, ano2, mes)
  arquivo <- paste0("dados/RD", uf, ano2, mes, ".dbc")
  
  tryCatch({
    download.file(url, destfile = arquivo, mode = "wb", quiet = TRUE)
    read.dbc(arquivo)
  }, error = function(e) {
    message("Não encontrado: ", url)
    NULL
  })
})

dados_sih_lista_<- dados_sih_lista |>  
  filter(MUNIC_RES == cod_municipio)

7.7 Parte 3 — Importação com pysus (Python)

O pysus é o equivalente do microdatasus para Python, permitindo baixar e processar dados do DATASUS diretamente.

Seção opcional: esta parte é indicada para participantes que já trabalham com Python ou querem integrar os dados do DATASUS a um fluxo Python/pandas. Se você usa apenas R, pode pular para a Parte 4 sem prejuízo — os dados produzidos aqui são equivalentes aos das Partes 1 e 2.

7.8 3.1 Instalação

# No terminal (ou prompt de comando)
pip install pysus

Requisitos: Python 3.8+ e pip instalados. Recomenda-se usar um ambiente virtual (venv ou conda).

7.9 3.2 Baixando dados do SIM

from pysus.online_data.SIM import download
import pandas as pd

# Definir código do município (IBGE, 7 dígitos)
cod_municipio = "3304557"  # Exemplo: Rio de Janeiro

dados_sim = download(
    states=["RJ"],
    years=[2020, 2021, 2022]
)

df_sim = dados_sim.to_dataframe()

print(df_sim.shape)
print(df_sim.head())

7.10 3.3 Filtrando pelo município

df_sim_municipio = df_sim[df_sim["CODMUNRES"] == cod_municipio]

print(f"Registros para o município {cod_municipio}: {len(df_sim_municipio)}")

7.11 3.4 Baixando dados do SIH

from pysus.online_data.SIH import download as download_sih

dados_sih = download_sih(
    group="RD",
    states=["RJ"],
    years=[2020, 2021, 2022],
    months=list(range(1, 13))
)

df_sih = dados_sih.to_dataframe()

df_sih_municipio = df_sih[df_sih["MUNIC_RES"] == cod_municipio]

7.12 3.5 Salvando os dados

# Parquet (eficiente para grandes volumes)
df_sim_municipio.to_parquet("dados/sim_municipio.parquet", index=False)
df_sih_municipio.to_parquet("dados/sih_municipio.parquet", index=False)

# Ou em CSV
df_sim_municipio.to_csv("dados/sim_municipio.csv", index=False)

7.13 3.6 Usando pysus dentro do RStudio com reticulate (opcional)

Subseção opcional: esta abordagem é para quem quer rodar código Python diretamente no RStudio, sem sair do ambiente R. Requer Python instalado e o pacote reticulate.

O pacote reticulate permite chamar Python a partir do R, compartilhando objetos entre as duas linguagens na mesma sessão do RStudio. Isso significa que você pode baixar dados com pysus em Python e, em seguida, analisá-los com tidyverse em R — sem precisar salvar e recarregar arquivos.

# Instalar o reticulate (se necessário)
install.packages("reticulate")
library(reticulate)

# Indicar qual instalação do Python usar.
# Se você usa conda:
use_condaenv("nome-do-seu-ambiente", required = TRUE)
# Se você usa o Python do sistema ou venv:
# use_python("/usr/bin/python3", required = TRUE)

# Verificar se o pysus está acessível
py_run_string("import pysus; print(pysus.__version__)")

Se não souber o caminho do Python, rode py_discover_config() no console do R — o reticulate lista as instalações encontradas e qual está sendo usada.

Após configurar o reticulate, você pode rodar blocos Python diretamente em um R Markdown (chunk com {python}) ou chamar via py_run_string():

# Chunk Python dentro de um R Markdown
from pysus.online_data.SIM import download

cod_municipio = "3304557"

dados_sim = download(states=["RJ"], years=[2020, 2021, 2022])
df_sim     = dados_sim.to_dataframe()

df_sim_municipio = df_sim[df_sim["CODMUNRES"] == cod_municipio]

print(df_sim_municipio.shape)

Logo após, em um chunk R do mesmo documento, o objeto fica disponível via py$:

# Acessar o DataFrame pandas como tibble no R
library(tidyverse)

sim_r <- py$df_sim_municipio   # py$ converte automaticamente para data.frame

glimpse(sim_r)

# Já é possível usar tidyverse normalmente
sim_r |>
  count(SEXO, name = "obitos") |>
  arrange(desc(obitos))

7.19 Carregando dados locais do município (para equipes com arquivos já em mãos!)

Quando usar esta parte: se a sua equipe já possui arquivos do SIM ou SIH baixados diretamente do DATASUS ou fornecidos pela Secretaria de Saúde, use esta seção diretamente. O resultado final será o mesmo.

7.20 4.1 Lendo arquivos .dbc

O formato .dbc é o formato nativo do DATASUS. Para lê-lo diretamente no R:

library(read.dbc)
library(tidyverse)

# Ler um arquivo .dbc local
sim_local <- read.dbc("caminho/para/DORJ2022.dbc") # modif

glimpse(sim_local)

7.21 4.2 Lendo arquivos .csv

Secretarias de Saúde frequentemente exportam os dados via TabWin, gerando .csv com separador ; e encoding Latin-1:

sim_local <-read_csv2(
  "caminho/para/sim_2022.csv",
  locale    = locale(encoding = "latin1"),
  col_types = cols(.default = "c")
)

Leia sempre como texto primeiro (col_types = cols(.default = "c")). Deixar o R adivinhar os tipos na leitura é a principal fonte de erros com dados do DATASUS — datas viram números, códigos de município perdem o zero à esquerda.

7.22 4.3 Lendo múltiplos arquivos de uma pasta

Se a equipe tiver vários arquivos por ano ou por mês numa mesma pasta:

# Listar todos os .dbc de uma pasta
arquivos_dbc <- list.files(
  path       = "caminho/para/pasta/",
  pattern    = "\\.dbc$",
  full.names = TRUE
)

# Ler e combinar todos
sim_local <- map(arquivos_dbc, read.dbc) |>
  bind_rows()

# O mesmo funciona para .csv
arquivos_csv <- list.files("caminho/para/pasta/", pattern = "\\.csv$", full.names = TRUE)

sim_local <- map(arquivos_csv, ~read_csv2(
  .x,
  locale    = locale(encoding = "latin1"),
  col_types = cols(.default = "c")
)) |>
  bind_rows()

7.23 4.4 Filtrando pelo código do município

Mesmo que o arquivo já seja do seu município, vale confirmar — arquivos fornecidos por Secretarias Estaduais costumam conter todos os municípios do estado:

cod_municipio <- "330455"  # substitua pelo código do seu município

sim_local <- sim_local |>
  filter(CODMUNRES == cod_municipio)

cat("Registros do município:", nrow(sim_local), "\n")

7.24 4.5 Verificação e correção de tipos

Após carregar os dados locais, é importante fazer uma verificação mínima nos dados antes de seguir adiante.

# Visão geral dos tipos atuais
glimpse(sim_local)

As correções mais comuns nos dados do DATASUS:

sim_local 
  mutate(
    # Datas: SIM usa formato DDMMAAAA
    DTOBITO  = dmy(DTOBITO),
    DTNASC   = dmy(DTNASC),

    # Códigos de município: sempre character (zeros à esquerda)
    CODMUNRES  = as.character(CODMUNRES),
    CODMUNOCOR = as.character(CODMUNOCOR),

    # Idade: numérico
    IDADE = as.integer(IDADE)
  )

Datas com formato errado não geram erro — geram NA silenciosamente. Após a conversão, verifique:

# Proporção de datas inválidas
sim_local |>
  summarise(
    n_total        = n(),
    na_dtobito     = sum(is.na(DTOBITO)),
    pct_na_dtobito = round(mean(is.na(DTOBITO)) * 100, 1)
  )

Se pct_na_dtobito for maior que 1–2%, algo está errado — provavelmente o formato da data (dmy vs ymd). Veja a tabela abaixo.

Sistema Formato original Função correta
SIM "15032022" (DDMMAAAA) dmy()
SINASC "15032022" (DDMMAAAA) dmy()
SIH "20220315" (AAAAMMDD) ymd()

Para o SIH, as correções equivalentes são:

sih_local 
  mutate(
    DT_INTER  = ymd(DT_INTER),
    DT_SAIDA  = ymd(DT_SAIDA),
    DIAS_PERM = as.integer(DIAS_PERM),
    VAL_TOT   = as.numeric(VAL_TOT),
    MUNIC_RES = as.character(MUNIC_RES),
    MUNIC_MOV = as.character(MUNIC_MOV)
  )

Nunca converta códigos de município para numeric — municípios com zero à esquerda (ex.: "050001") perdem o zero e viram um código inexistente.
